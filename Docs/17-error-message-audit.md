# 用户可见报错说明检查

2026 年 10 月 20 日，继续检查技能诊断以外的报错。此次重点处理只说“无效”“格式不符”“前置不足”，却没有指出位置、实际值、要求及处理办法的高频路径。

## 已改进的提示

| 范围 | 新增说明 |
| --- | --- |
| 普通数值 | 配装／物品字段、输入值和允许范围；非法值不输出整份存档 |
| 节点与树版本 | 被动或技能名称、节点编号、已分配点数和节点上限；前置节点及其当前可成立点数、基础职业 20 点门槛；配装与工具支持的树版本 |
| 专精槽 | 具体槽位、技能名称、槽位要求的角色等级、当前同步等级；重复技能或重复槽位 |
| 上传 | 出错文件名、超大文件实际 MiB 数与 32 MiB 限制、重复载入的原生文件名、每批文件数；浏览器读取失败保留原错误原因并使用 FILE_READ |
| 仓库与世界编辑 | 已上传与预期仓库名称及赛季；具体世界线、普通／强化难度、稳定值／腐化值和允许范围；阵营阶级／恩惠字段与输入值 |
| 物品与神像 | 装备部位、来源路径、物品编号及处理建议；神像条目、坐标、尺寸、冲突的另一条目或祭坛禁用格 |
| 战役与终局 | 异常字段、任务列表下标／任务编号／步骤、任务或被动字段预期类型；重复资源名称和数量，以及相关角色／仓库文件名 |
| 仓库合并 | 具体资源、两侧数量、相加结果、2147483647 上限及重新上传前的处理建议 |
| 过滤器 | 权重阈值的实际输入与范围、未知选择编号、启用但无词缀的神像条目，以及关闭条目／重新选择的操作建议 |

例如：普通“流亡者的陨落”的腐化输入为 51 时，会明确列出该世界线与难度、当前输入以及 0–50 的整数范围。两件神像重叠时会说明第几项与第几项冲突，而不只显示“重叠”。

## 界面和兼容性

[diagnostic-context.js](../web/src/core/diagnostic-context.js) 为错误保留文件上下文、限制异常值的显示长度，并为英文消息清理中文字段注释。[planner-diagnostics.js](../web/src/core/planner-diagnostics.js) 补充节点条件说明。

显式中英文消息直接显示对应语言，避免用户输入中的“ / ”被误当成语言分隔符。过滤器通知现在保留结构化错误对象，切换语言后仍可显示完整说明；FilterError 的原 message 格式和 code 保留，另提供 messageZh 与 messageEn。

此次保留原有范围、节点顺序重建、任务完成判断、仓库归属及资源合并规则。神像占用从 Set 改用 Map 仅用于记住冲突条目，判断的格位不变。失败路径不导出部分修改；数据不自动补造或手工修复。

已有明确操作指引的链接错误、网络超时、缺少全局索引／仓库页、原 XML 缺少设置等提示继续保留。未知格式或未验证的装备特性仍不能提供安全的自动修复；提示用于定位文件、字段及来源条目，不代表未知格式已经受支持。节点目录目前只包含编号和数值规则，因此节点以树名称及编号定位，不编造未提取的节点名称。
