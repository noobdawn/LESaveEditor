# 技能导入错误的具体说明

2026 年 10 月 20 日，针对公开配装 [QWXr0dxZ](https://www.lastepochtools.com/planner/zh/QWXr0dxZ) 和 [B4XP4b8d](https://www.lastepochtools.com/planner/zh/B4XP4b8d)，改善技能错误提示。原先只显示“角色尚未解锁此技能”或“技能分配点数超过配装技能等级”，未说明具体技能和数值。

## 界面行为

- 显示游戏数据中的技能名称，以及实际的技能栏格位或专精槽位。界面位置从 1 开始编号，内部 slotNumber 保持从 0 开始。
- 未解锁时，列出所需角色等级／专精／对应被动树点数、同步后角色的实际值和差额。多个替代解锁条件明确表示“任一条件”；超过 22 点的其他专精技能仍要求选择对应专精。
- 超点时列出技能等级、已分配点数和超出数量。同一批专精技能的超点问题一次列出，逐项提供回收点数或检查技能等级加成的建议。
- 职业不匹配时列出技能名称、所在位置及当前职业。
- 每项错误提供独立中英文消息。错误面板原有换行样式和 HTML 转义保持有效，英文界面不会显示中文错误。

例如，QWXr0dxZ 显示：技能栏第 4 格「Frost Wall」未解锁，符文大师需要 15 点，当前 13 点，缺少 2 点。B4XP4b8d 同时显示三个问题：专精第 2 槽 Meteor 为 24 级分配 25 点；第 3 槽 Flame Ward 为 26 级分配 27 点；第 4 槽 Black Hole 为 33 级分配 35 点。

## 实现与边界

[planner-diagnostics.js](../web/src/core/planner-diagnostics.js) 根据游戏技能名称、界面语言中的职业／专精名称及数值条件构造说明。[planner.js](../web/src/core/planner.js) 保留原错误 code 和首项 treeID 等字段，并通过 details.issues 提供问题列表，messageEn 用于英文界面。

本次不降低节点、技能解锁或等级校验。普通分享配装分配超过声明等级仍被拒绝；fromSaveFile=2 的既有天梯加成处理保留。所有判断基于同步后的角色等级、职业和被动分配。其他不同类型的校验仍按原顺序执行，不承诺一次列出所有格式及兼容性错误。
