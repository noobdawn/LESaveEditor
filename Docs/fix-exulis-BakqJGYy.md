# Exulis 固定词缀导入修复

公开配装：https://www.lastepochtools.com/planner/zh/BakqJGYy

流亡 / Exulis（469）的 1083/T7 和 1087/T8 分别位于模拟器的 sealedAffix、primordialAffix 字段，均属于该暗金的固定词缀池。旧导入器仅允许类型 7 的固定变体使用这两个字段，漏掉了 Exulis 的类型 6（Corruption），误报“此暗金的封印词缀不在已验证变体池中”。

修复按所属暗金的已验证词缀池识别固定来源，保留原阶级和 Roll。类型 6 仍使用原有传奇稀有度及预腐化标记，不套用类型 7 保留 LP 的规则。池外封印、重复词缀、无效阶级及 LP 组合继续拒绝。

回归测试覆盖该公开配装的完整同步、复核、下载，普通及最大 Roll 模式，以及五条 Exulis 固定词缀在两个辅助字段中的识别。全套测试 208 项通过、4 项可选私人副本测试跳过，生产构建通过；游戏内载入尚未验收。
