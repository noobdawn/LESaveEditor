# 产品设计与操作流程

[返回项目说明](../README.md)

当前产品采用“原站配装，本工具同步离线存档”的分工。用户在 LastEpochTools 完成配装，通过公开分享链接导入本工具，再选择修改范围、上传文件、检查变化并下载。网页不需要后端服务，最终用户也不需要 Python 或油猴脚本。

## 设计选择

LastEpochTools 负责完整的装备选择、技能树和配装模拟。本项目负责将分享数据转换为当前游戏可读的存档结构，并提供有限的进度编辑。原站分享 ID 通过标准 LZ-string 协议解析，物品和节点再由本地游戏目录校验；项目没有镜像原站前端脚本或重建其完整模拟器。

当前界面使用原生 JavaScript 生成 HTML，样式集中在 `styles.css`。这是单页五步会话，步骤由 `state.step` 控制，没有前端路由框架或每步独立 URL。

## 五个步骤

| 步骤编号 | 页面 | 用户操作 | 代码入口 |
| --- | --- | --- | --- |
| 0 | 配装链接 | 输入模拟器分享 URL，读取配装 | `linkPage()`、`flow.importBuild()` |
| 1 | 配装同步 | 选择同步分区及两个可选开关 | `syncPage()`、`flow.setOption()` |
| 2 | 上传存档 | 拖入或选择角色及可选仓库 | `uploadPage()`、`loadFiles()`、`flow.addFiles()` |
| 3 | 世界编辑 | 修改已有世界线和阵营 | `worldPage()`、`timelineEditor()`、`factionEditor()` |
| 4 | 修改预览 | 核对差异、确认、逐文件下载 | `reviewPage()`、`reviewRows()`、`flow.downloads()` |

入口页面直接显示 URL 输入框。下方“我想修改自己的存档怎么办？”打开教学对话框：在原站 Import 中导入离线角色，完成调整，再保存分享链接。演示文件是 `web/public/tutorial/save-to-planner.gif`。

## 过滤器分支

链接页在原有同步入口旁增加“构造过滤器”。该分支不需要存档，保留浅色背景、绿色按钮、语言切换及返回链接页的体验；原五步同步流程独立保留。

过滤器采用四步确认：需求暗金、高价值词缀、中价值词缀、分组与导出。用户编辑物品和词缀集合，无须配置每条底层规则。需求暗金合并为一个逻辑组；套装独立归入高价值套装。普通装备取明确附加词缀；暗金本体属性不加入装备价值池。神像按形状维护单独的目标词缀。

通用生命、耐伤、护盾、属性、抗性、护甲、防御与功能词缀默认勾选。高价值优先于中价值，同一词缀只属于一个池。取消通用项后可重新勾选，也可搜索增加；其余词缀隐式归为低价值，不展示巨大低价值清单。

最终页面提供可编辑的装备组，每组有名称、启用开关和百分比门槛（100% = 4 条高价值 T7），支持滑杆和数字输入，可随时添加或删除。默认门槛为 100%、70%、45%；用户可新增过渡组，开荒结束后停用并保留配置。输入时即时更新门槛和示例，提交后按门槛从高到低排列；同门槛按添加顺序匹配。

评分区提供高价值、有效、无效三类词缀的 T7–T1 可编辑分数和“恢复默认”。默认分别为 `10 / 5 / 2 / 1.6 / 1.2 / 0.8 / 0.4`、`4 / 2 / 1 / 0.8 / 0.6 / 0.4 / 0.2`、`2 / 1 / 0 / -0.2 / -0.2 / -0.2 / -0.2`。总分为各词缀分数之和，空槽为零，封印等额外词缀也计入，T8 按 T7 计分。支持负数及最多两位小数；无额外的统一扣分；百分比按当前高价值 T7 分数线性换算，旁边显示对应总分。高价值 T7 必须大于零。评分细节放在折叠区，不在标题下堆叠说明。

每组可选择显示或隐藏、颜色和强调。停用不生成该组规则，物品继续匹配后续组；隐藏代表命中后终止。高门槛组默认更醒目。生成器优先精确转换；超出 200 条或原生计数限制时，允许向更高价值组保守合并，提示“近似过滤：可能多保留部分装备”。近似不会漏掉达标装备；评分组设为隐藏时若需要近似，则阻止导出，避免误藏。暗金与套装的相对稀有判定仅采用已知随机池信息，无法推导未知 Boss 掉率。

切换语言、返回前一步或重新进入同一 Build 保留编辑；导入另一 Build 重建需求与候选缓存。过滤器样式仅限 `.filter-workbench` 与入口局部区域，不修改原全局主题。实现位于 `core/value-filter.js`、`core/equipment-score-compiler.js`、`filter-workbench.js` 与 `filter-workbench.css`。

## 同步选项

| 选项 | 默认值 | 当前含义 |
| --- | --- | --- |
| 装备 | 开 | 同步装备槽，包括神像祭坛 |
| 神像 | 开 | 同步神像及其布局 |
| 祝福 | 开 | 同步十个世界线祝福槽 |
| 被动天赋 | 开 | 同步合法节点分配 |
| 技能专精 | 开 | 同步技能、槽位、节点和基础经验 |
| 技能栏 | 开 | 同步五个快捷栏位置 |
| 词缀最大 Roll 值 | 关 | 将本次新生成物品的 Roll 设为 255 |
| 速通至异界 | 关 | 补齐战役进度、传送点和任务奖励，设置异界大厅登录地点 |
| 等级、职业、专精 | 强制开 | 不显示可取消选项，由工作流强制同步 |

发生职业或专精变化时，必须同时同步天赋、技能专精和技能栏；取消其中一项会被核心逻辑拒绝。选中的物品分区整体替换，旧物品不会自动移入背包。最大 Roll 不提高词缀层级或传奇潜能，也不修改未同步物品。

速通开关旁的感叹号使用 `aria-describedby` 关联提示，支持鼠标悬停和键盘聚焦。提示说明任务范围、奖励上限、登录地点及保留内容。

## 文件和世界编辑交互

一次会话最多载入一个角色文件与一个同赛季、同硬核模式的仓库文件。角色必需，仓库只在阵营编辑时需要；页面根据角色显示对应仓库名。底层解析器能识别更多文件种类，但五步工作流仅接收角色和赛季仓库。

世界线下拉项来自角色已有的 `monolithRuns`，普通和强化难度分别显示。稳定值与腐化值有不同边界，快捷按钮分别增加 1000 和 50，并停在上限。全新角色没有回响记录时，先在游戏中开启异界内容，再重新上传文件编辑数值。

阵营下拉项来自角色与匹配仓库共有的已验证记录。变更阶级时重置本阶声望，并同步两个文件；保留同阶或只修改恩惠时不重置声望。页面提供逐阶声望表，遗忘骑士团使用先兆进度规则。

上传和下载页都显示通用存档位置：

```text
%USERPROFILE%\AppData\LocalLow\Eleventh Hour Games\Last Epoch\Saves
```

## 预览和下载

预览以原始上传文件为比较基准，显示角色设置、战役进度、世界线和阵营变化。装备、神像、祝福、天赋与技能明细使用可展开分组，避免直接展示字节数组。同步提示独立列出版本迁移、额外技能等级等情况。

用户勾选“我已了解以上修改，并已备份原始存档”后才能下载。下载的是分别命名的原生存档，只提供实际发生变化的文件，不生成 ZIP。编辑或返回前一步会取消确认；重新修改后必须再次核对。

## 状态和视觉约束

界面保持简洁，使用浅色背景、绿色操作按钮和有限的说明文字，不加入装饰性宣传句。页面标题直接命名功能，例如“高价值词缀”；标题下不加复述操作的介绍段。必要的匹配条件、错误及限制保留简短说明。中英文入口固定在右上角；文案在 `i18n.js`，世界线和阵营名称在 `world-data.json`。部分装备和技能专有名称仍来自英文游戏数据。

会话数据保存在内存，刷新或关闭会清空。仅语言偏好通过 `le-save-editor-language` 保存到 `localStorage`。读取配装或文件时禁用相关操作；读取失败显示具体错误，不进入下一步。页面提供离开时的未完成会话提醒，并在换步骤时移动焦点、滚动到顶部。
