# 三联入口与回归验证

本地预览：`npm run dev`，访问首页。本次界面调整已通过用户验收与功能回归验证。

入口三页无间隙铺满整个视口，去除页眉、页脚和宣传文案。从左到右为「过滤器构造」「离线存档同步」「世界编辑」，继续使用深绿、白色和浅绿。默认突出同步；鼠标悬停或键盘聚焦时对应页面展开，只显示对应功能要点。点击后选中页扩展至全屏并淡出，约 1.16 秒后再加载工作流程。

- `?entry=filter`：专用配装输入与 XML 导入，进入现有过滤器流程。
- `?entry=sync`：专用配装输入，进入现有五步同步流程。
- `?entry=world`：直接进入上传存档，继续独立世界编辑流程。

点击工作页品牌返回首页；世界编辑初始上传页的返回操作也返回首页。入口不读取存档或请求配装。沿用工作页语言偏好；窄屏改为上下排列并铺满视口。页面切换使用约 900 毫秒的宽度、颜色、图形与内容过渡；按本次预览要求，入口始终保留动画，不受系统减少动画设置影响。

实现：`web/src/entry-bootstrap.js` 按入口延迟加载，`entry-landing.js` 和 `entry-landing.css` 负责入口与过渡，`main.js` 保留现有编辑逻辑并接受入口参数。
